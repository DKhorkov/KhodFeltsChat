# Пакет handlers/default

## Назначение

Обработчик по умолчанию для неизвестных маршрутов. Отдаёт HTML-страницу `home.html` с навбаром.

## Маршрут

`GET /` → `Handler(w, r)`

## Реализация

Шаблон `home.html` + `navbar.html` парсится один раз (`sync.Once`). При ошибке рендеринга — `RenderError` с кодом 500.
