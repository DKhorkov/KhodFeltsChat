# web/static/js

## Назначение

Клиентский JavaScript веб-интерфейса. Каждый файл подключается к соответствующему
HTML-шаблону через `<script>`. Общие утилиты (`auth.js`, `validation.js`,
`errors-mapper.js`, `alert-modal.js`) подключаются на всех страницах.

## Файлы и функции

### auth.js — Авторизованные запросы

| Функция | Описание |
|---------|----------|
| `fetchWithAuth(url, options)` | Обёртка над `fetch` с `credentials: 'same-origin'`. При 401 автоматически обновляет JWT через `PUT /api/sessions` и повторяет запрос. |

### chat.js — Страница чатов (основной модуль)

**Константы и глобальное состояние:**

| Переменная | Описание |
|------------|----------|
| `MESSAGES_PAGE_SIZE` | Размер страницы сообщений (50). |
| `SEARCH_DEBOUNCE_MS` | Задержка debounce для поиска (300 мс). |
| `CHAT_LIST_POLL_INTERVAL_MS` | Интервал polling списка чатов (5000 мс). |
| `IS_MOBILE` | Флаг мобильного устройства (по userAgent или ширине экрана ≤ 600px). |
| `SWIPE_CLOSE_THRESHOLD_RATIO` | Доля ширины экрана для закрытия чата свайпом (0.5 = 50%). |
| `SWIPE_LOCK_ANGLE_PX` | Минимальное смещение в пикселях до определения направления свайпа (15px). |
| `currentUser` | Текущий авторизованный пользователь. |
| `selectedChatId` / `selectedChat` | ID и объект выбранного чата. |
| `messages` | Массив сообщений текущего чата. |
| `ws` | WebSocket-соединение. |
| `isLoadingMore` / `hasMoreMessages` | Флаги пагинации сообщений. |
| `returnToGroupChat` | Чат для возврата из профиля участника в модалку группового чата. |
| `chatsList` | Массив текущих чатов для делегированного обработчика кликов (обновляется в `renderChatList`). |

**Инициализация:**

| Функция | Описание |
|---------|----------|
| `DOMContentLoaded` handler | Загружает пользователя, чаты, WebSocket, web-push. Устанавливает все обработчики. Обрабатывает открытие чата по query-параметру из push-уведомления. Запускает polling списка чатов. |
| `loadCurrentUser()` | Загружает текущего пользователя через `GET /api/users/me`. При ошибке возвращает `null`. |
| `setupEscapeHandler()` | Глобальный обработчик Escape: закрывает модалки по приоритету (профиль участника → групповой чат → поиск → создание чата), затем закрывает панель чата. |

**WebSocket:**

| Функция | Описание |
|---------|----------|
| `connectWebSocket()` | Подключается к `ws(s)://.../api/ws`. Входящие сообщения: дедупликация оптимистичных, добавление в UI, toast для сообщений из других чатов. При закрытии — автопереподключение через 3 сек. |

**Список чатов:**

| Функция | Описание |
|---------|----------|
| `loadChats()` | Загружает список чатов через `GET /api/chats` и перерисовывает UI. |
| `debouncedLoadChats()` | Debounced-версия `loadChats()` (300 мс). |
| `renderChatList(chats)` | Рендерит список чатов в `#chat-list`. Сохраняет чаты в `chatsList`. Каждый элемент получает `data-chat-id` для делегированного обработчика. Непрочитанные отмечаются точкой и жирным шрифтом. Под названием чата отображается превью последнего сообщения (`.chat-item__last-message`) в формате «Отправитель: текст» (для своих — «Вы: текст»). |
| `setupChatListDelegation()` | Устанавливает один делегированный обработчик `click` на контейнер `#chat-list` (вызывается один раз при инициализации). Клик по аватару (`[data-action="avatar"]`) → `openChatInfo`, клик по элементу чата (`.chat-item`) → `selectChat`. Решает проблему iOS Safari: при пересоздании DOM-элементов (`innerHTML = ''`) hit-test кэш WebKit инвалидируется, и первый тап по новым элементам игнорируется. Делегирование на стабильный контейнер обходит эту проблему. |
| `getChatTitle(chat)` | Возвращает название чата: `chat.title`, имя собеседника (для приватных) или `'Чат #ID'`. |
| `getOtherMember(chat)` | Возвращает собеседника в приватном чате (исключая текущего пользователя). |
| `openChatById(chatId)` | Загружает список чатов и открывает чат по ID. Используется для перехода из push-уведомлений. |

**Выбор чата и загрузка сообщений:**

| Функция | Описание |
|---------|----------|
| `selectChat(chat)` | Выбирает чат: сбрасывает состояние, показывает панель переписки, загружает сообщения, подписывается на подгрузку старых при скролле вверх. |
| `loadMessages(chatId, offset)` | Загружает страницу сообщений через `GET /api/chats/{id}/messages`. Разворачивает порядок (API отдаёт от новых к старым). При `offset=0` — полная перерисовка, иначе prepend. |
| `serverMessageCount()` | Количество серверных (не оптимистичных) сообщений — используется как offset для пагинации. |
| `loadMoreMessages()` | Подгружает следующую страницу старых сообщений. Guard: `isLoadingMore`, `hasMoreMessages`. |

**Рендеринг сообщений:**

| Функция | Описание |
|---------|----------|
| `renderMessages()` | Полная перерисовка всех сообщений в `#messages-list`. Вставляет разделитель «Новые сообщения» перед первым непрочитанным. |
| `prependMessages(olderMessages)` | Вставляет старые сообщения в начало контейнера (для бесконечного скролла вверх). |
| `appendMessageBubble(message)` | Добавляет одно сообщение в конец контейнера. |
| `createMessageBubble(message)` | Создаёт DOM-элемент пузыря сообщения (sender, time, text). Свои сообщения помечаются классом `--own`. |
| `isFirstUnread(message, index)` | Определяет, является ли сообщение первым непрочитанным (для разделителя). |
| `scrollToBottom()` | Прокрутка контейнера сообщений вниз через `requestAnimationFrame`. |
| `formatTime(dateStr)` | Форматирует дату в `ru-RU` локали (`toLocaleString`). |
| `formatDate(dateStr)` | Форматирует дату в `ru-RU` локали (день, месяц, год). |

**Отправка сообщений:**

| Функция | Описание |
|---------|----------|
| `setupSendMessage()` | Настраивает обработчики ввода: кнопка Send, Enter (на десктопе — отправка, на мобильном — перенос строки), Shift+Enter — перенос строки. |
| `sendMessage()` | Отправляет сообщение через WebSocket, добавляет оптимистичный bubble, помечает все сообщения прочитанными, очищает поле ввода, немедленно обновляет список чатов. |
| `markAllAsRead()` | Помечает все сообщения в текущем чате как прочитанные, удаляет разделитель «Новые сообщения». |

**Emoji picker:**

| Функция | Описание |
|---------|----------|
| `setupEmojiPicker()` | Настраивает toggle-кнопку emoji picker. Lazy-init: `createEmojiPicker` вызывается при первом открытии. Выбранный emoji вставляется в позицию курсора в textarea. |

**Закрытие чата:**

| Функция | Описание |
|---------|----------|
| `setupCloseChat()` | Обработчик кнопки закрытия чата (`#btn-close-chat`). |
| `lockPageScroll()` | Блокирует горизонтальный скролл на `html` и `body` (`overflowX: hidden`). Вызывается при начале свайпа, чтобы `translateX` на conversation не сдвигал всю страницу (включая navbar). |
| `unlockPageScroll()` | Снимает блокировку горизонтального скролла. Вызывается после завершения анимации свайпа (закрытие или возврат на место). |
| `setupSwipeToCloseChat()` | Свайп вправо для закрытия чата на мобильных (только при `window.innerWidth ≤ 600`, совпадает с CSS media query). Интерактивный: conversation сдвигается по `touchmove` через `translateX`, открывая sidebar под ним. При свайпе ≥ 50% ширины экрана (`SWIPE_CLOSE_THRESHOLD_RATIO`) — чат закрывается с анимацией; иначе — возвращается на место. Направление жеста определяется один раз после 15px смещения (`SWIPE_LOCK_ANGLE_PX`): если горизонтальное смещение больше вертикального — свайп, иначе — обычный скролл. CSS-часть: `.chat-layout--chat-open` получает `overflow: hidden` и `position: relative`, conversation — `position: absolute; z-index: 10`, sidebar остаётся `display: flex` (виден под conversation). |
| `closeChat()` | Сбрасывает состояние чата, скрывает панель переписки, убирает класс `chat-layout--chat-open`, закрывает emoji picker. |

### navbar.js — Навбар и профиль

**Утилиты модалок (блокировка скролла фона):**

| Функция / Константа | Описание |
|---------|----------|
| `MODAL_IDS` | Список ID всех модалок приложения — используется для проверки, остались ли открытые модалки. |
| `openModal(modalEl)` | Показывает модалку и блокирует скролл `body` (`overflow: hidden`). |
| `closeModal(modalEl)` | Скрывает модалку и снимает блокировку скролла `body`, если не осталось других открытых модалок. |

**Тема:**

| Функция | Описание |
|---------|----------|
| `applyTheme(themeDark)` | Устанавливает атрибут `data-bs-theme`, сохраняет в `localStorage`, обновляет UI переключателя. |
| `isDarkTheme()` | Проверяет текущую тему по атрибуту `data-bs-theme`. |
| `toggleTheme()` | Переключает тему и сохраняет на сервер через `saveSettings`. |
| `updateThemeSwitchUI()` | Синхронизирует UI toggle-переключателя темы с текущим состоянием. |
| `clearTheme()` | Сбрасывает тему на светлую, очищает `localStorage`. |

**Настройки:**

| Функция | Описание |
|---------|----------|
| `currentSettings` | Глобальное состояние настроек пользователя — хранится для отправки полного объекта при обновлении. |
| `saveSettings(patch)` | Сохраняет настройки через `PUT /api/users/me/settings`. Мержит patch в `currentSettings`. |
| `updateSwitchUI(switchEl, on)` | Обновляет визуальное состояние toggle-переключателя (track + thumb). |
| `hasConsent(mask, bit)` | Проверяет наличие бита согласия в битовой маске. |
| `toggleConsent(mask, bit)` | Переключает бит согласия в битовой маске. |

**Web Push (подписка):**

| Функция | Описание |
|---------|----------|
| `urlBase64ToArrayBuffer(base64String)` | Декодирует base64url в `ArrayBuffer` (для VAPID ключа). Использует `.buffer.slice(0)` для совместимости с iOS. |
| `arrayBufferToBase64Url(buffer)` | Кодирует `ArrayBuffer` в base64url строку. |
| `subscribeToWebPush(registration)` | Получает VAPID ключ с сервера, подписывается на push, отправляет подписку на сервер. |
| `sendWebPushSubscriptionToServer(subscription)` | Отправляет push-подписку через `POST /api/web-push/subscribe`. Сохраняет ID в `localStorage`. |
| `isIOSSafari()` | Проверяет, является ли браузер Safari на iOS. |
| `isStandaloneMode()` | Проверяет режим PWA (standalone). |
| `showWebPushBanner()` | Показывает баннер для запроса разрешений на iOS (требует user gesture). Один раз за сессию (`sessionStorage`). |
| `checkExistingWebPushSubscription()` | Проверяет наличие существующей push-подписки без запроса разрешения. |
| `ensureBrowserWebPushSubscription()` | Полный цикл: регистрация SW → проверка подписки → запрос разрешения → подписка. На iOS требует standalone-режим. |
| `removeBrowserWebPushSubscription()` | Отписывается от push в браузере и удаляет подписку на сервере. |

### errors-mapper.js — Маппинг ошибок

| Функция | Описание |

### validation.js — Клиентская валидация

| Функция | Описание |
