# web/static/js

## Назначение

Клиентский JavaScript веб-интерфейса. Каждый файл подключается к соответствующему
HTML-шаблону через `<script>`. Общие утилиты (`auth.js`, `validation.js`,
`errors-mapper.js`, `alert-modal.js`) подключаются на всех страницах.

## Файлы и функции

### auth.js — Авторизованные запросы

| Функция | Описание |
|---------|----------|
| `fetchWithAuth(url, options)` | Обёртка над `fetch` с `credentials: 'same-origin'`. При 401 автоматически обновляет JWT через `PUT /api/sessions` и повторяет запрос. |

### chat.js — Страница чатов (основной модуль)

**Константы и глобальное состояние:**

| Переменная | Описание |
|------------|----------|
| `MESSAGES_PAGE_SIZE` | Размер страницы сообщений (50). |
| `SEARCH_DEBOUNCE_MS` | Задержка debounce для поиска пользователей (300 мс). |
| `CHAT_LIST_DEBOUNCE_MS` | Задержка debounce для обновления списка чатов (300 мс). |
| `CHAT_LIST_POLL_INTERVAL_MS` | Интервал polling списка чатов (5000 мс). |
| `WS_RECONNECT_DELAY_MS` | Задержка переподключения WebSocket (3000 мс). |
| `EMOJI_CLOSE_DELAY_MS` | Задержка закрытия emoji picker после ухода курсора (500 мс). |
| `LONG_PRESS_DELAY_MS` | Длительность долгого нажатия для контекстного меню на мобильных (500 мс). |
| `TOAST_DURATION_MS` | Время отображения toast-уведомления (3000 мс). |
| `IS_MOBILE` | Флаг мобильного устройства (по userAgent или ширине экрана ≤ 600px). |
| `SWIPE_CLOSE_THRESHOLD_RATIO` | Доля ширины экрана для закрытия чата свайпом (0.5 = 50%). |
| `SWIPE_LOCK_ANGLE_PX` | Минимальное смещение в пикселях до определения направления свайпа (15px). |
| `SWIPE_REPLY_THRESHOLD_PX` | Минимальное смещение влево для активации ответа на сообщение (80px). |
| `currentUser` | Текущий авторизованный пользователь. |
| `selectedChatId` / `selectedChat` | ID и объект выбранного чата. |
| `messages` | Массив сообщений текущего чата. |
| `ws` | WebSocket-соединение. |
| `isLoadingMore` / `hasMoreMessages` | Флаги пагинации сообщений. |
| `returnToGroupChat` | Чат для возврата из профиля участника в модалку группового чата. |
| `chatsList` | Массив текущих чатов для делегированного обработчика кликов (обновляется в `renderChatList`). |
| `unreadMessageIds` | `Set<number>` ID сообщений, прилетевших в открытый чат с момента отскролла от низа. Хранится как Set (а не число), чтобы при `message_deleted` корректно вычесть удалённое сообщение из бейджа. Сбрасывается, когда последнее сообщение снова видно или при `resetScrollDownState`. |
| `isAtBottom` | Видно ли последнее сообщение открытого чата (управляется `IntersectionObserver` на последнем `.message-bubble`). |
| `lastMessageObserver` | `IntersectionObserver` на последнем `.message-bubble` (root — `#messages-list`, threshold 0.1). |

**Инициализация:**

| Функция | Описание |
|---------|----------|
| `DOMContentLoaded` handler | Загружает пользователя, чаты, WebSocket, web-push. Устанавливает все обработчики. Обрабатывает открытие чата по query-параметру из push-уведомления. Запускает polling списка чатов. |
| `loadCurrentUser()` | Загружает текущего пользователя через `GET /api/users/me`. При ошибке возвращает `null`. |
| `setupEscapeHandler()` | Глобальный обработчик Escape: отменяет режим редактирования/ответа, закрывает модалки по приоритету (профиль участника → групповой чат → поиск → создание чата), затем закрывает панель чата. |

**WebSocket:**

| Функция | Описание |
|---------|----------|
| `connectWebSocket()` | Подключается к `ws(s)://.../api/ws`. Обрабатывает события `new_message`, `message_deleted`, `message_edited`. Все обработчики вызываются как async с `.catch()` для перехвата ошибок. Toast для сообщений из других чатов. При закрытии — автопереподключение через 3 сек. |
| `handleNewMessage(message)` | (async) Обрабатывает входящее сообщение. В открытом чате: снимок `wasAtBottom` ДО рендера, затем `appendMessageBubble`. Если своё или `wasAtBottom` — `scrollToBottom()` (follow mode); иначе — `unreadMessageIds.add(message.id)` без скролла. Toast для сообщений из других чатов. Обновляет список чатов. |
| `handleMessageDeleted(payload)` | (async) Удаляет сообщение из UI по `payload.messageId`. Пересчитывает позицию разделителя «Новые сообщения» через `updateUnreadDivider()`. Переподписывает observer на новый последний bubble через `reobserveLastMessage()`. Если удалённое сообщение было в `unreadMessageIds` — вычитает его и обновляет badge. Логирует предупреждение если ID не найден. Обновляет список чатов. |
| `handleMessageEdited(payload)` | (async) Обрабатывает WS-событие `message_edited`. Получает обновлённое сообщение через `GET /api/messages/{id}`, обновляет текст и время в DOM-элементе. Обновляет список чатов. |

**Список чатов:**

| Функция | Описание |
|---------|----------|
| `loadChats()` | Загружает список чатов через `GET /api/chats` и перерисовывает UI. |
| `debouncedLoadChats()` | Debounced-версия `loadChats()` (300 мс). |
| `renderChatList(chats)` | Рендерит список чатов в `#chat-list`. Сохраняет чаты в `chatsList`. Каждый элемент получает `data-chat-id` для делегированного обработчика. Непрочитанные отмечаются точкой и жирным шрифтом. Под названием чата отображается превью последнего сообщения (`.chat-item__last-message`) в формате «Отправитель: текст» (для своих — «Вы: текст»). |
| `setupChatListDelegation()` | Устанавливает один делегированный обработчик `click` на контейнер `#chat-list` (вызывается один раз при инициализации). Клик по аватару (`[data-action="avatar"]`) → `openChatInfo`, клик по элементу чата (`.chat-item`) → `selectChat`. Решает проблему iOS Safari: при пересоздании DOM-элементов (`innerHTML = ''`) hit-test кэш WebKit инвалидируется, и первый тап по новым элементам игнорируется. Делегирование на стабильный контейнер обходит эту проблему. |
| `getChatTitle(chat)` | Возвращает название чата: `chat.title`, имя собеседника (для приватных) или `'Чат #ID'`. |
| `getOtherMember(chat)` | Возвращает собеседника в приватном чате (исключая текущего пользователя). |
| `openChatById(chatId)` | Загружает список чатов и открывает чат по ID. Используется для перехода из push-уведомлений. |

**Выбор чата и загрузка сообщений:**

| Функция | Описание |
|---------|----------|
| `selectChat(chat)` | Выбирает чат: сбрасывает состояние, показывает панель переписки, загружает сообщения, подписывается на подгрузку старых при скролле вверх. |
| `loadMessages(chatId, offset)` | Загружает страницу сообщений через `GET /api/chats/{id}/messages`. Разворачивает порядок (API отдаёт от новых к старым). При `offset=0` — полная перерисовка, иначе prepend. |
| `serverMessageCount()` | Количество загруженных сообщений — используется как offset для пагинации. |
| `loadMoreMessages()` | Подгружает следующую страницу старых сообщений. Guard: `isLoadingMore`, `hasMoreMessages`. |

**Рендеринг сообщений:**

| Функция | Описание |
|---------|----------|
| `renderMessages()` | Полная перерисовка всех сообщений в `#messages-list`. Вставляет разделитель «Новые сообщения» перед первым непрочитанным. |
| `prependMessages(olderMessages)` | Вставляет старые сообщения в начало контейнера (для бесконечного скролла вверх). |
| `appendMessageBubble(message)` | Добавляет одно сообщение в конец контейнера. |
| `createMessageBubble(message)` | Создаёт DOM-элемент пузыря сообщения (sender, time, text). Свои сообщения помечаются классом `--own`. |
| `isFirstUnread(message, index)` | Определяет, является ли сообщение первым непрочитанным (для разделителя). |
| `updateUnreadDivider()` | Пересчитывает позицию единственного разделителя «Новые сообщения»: убирает старый, находит первое непрочитанное сообщение через `isFirstUnread()` и вставляет divider перед его bubble. Аналог реактивного пересчёта в GUI-версии. |
| `scrollToBottom()` | Прокрутка контейнера сообщений вниз через `requestAnimationFrame` (мгновенно). Используется при открытии чата, отправке своего сообщения и в follow mode. |
| `formatTime(dateStr)` | Форматирует дату в `ru-RU` локали (`toLocaleString`). |
| `formatDate(dateStr)` | Форматирует дату в `ru-RU` локали (день, месяц, год). |

**Отправка сообщений:**

| Функция | Описание |
|---------|----------|
| `setupSendMessage()` | Настраивает обработчики ввода: кнопка Send, Enter (на десктопе — отправка, на мобильном — перенос строки), Shift+Enter — перенос строки. |
| `sendMessage()` | Если активен режим редактирования — вызывает `updateMessage()`, иначе отправляет новое сообщение через WebSocket, помечает все сообщения прочитанными, очищает поле ввода, возвращает фокус на input (чтобы клавиатура не закрывалась на мобильных). UI обновляется по WS-событию от сервера. |
| `markAllAsRead()` | Помечает все сообщения в текущем чате как прочитанные, удаляет разделитель «Новые сообщения». |

**Контекстное меню сообщений:**

| Функция | Описание |
|---------|----------|
| `setupContextMenu()` | Настраивает контекстное меню для сообщений: правый клик (контекстное меню) или долгий тап на мобильных. На мобильных при long press сообщение плавно увеличивается (CSS-анимация `message-bubble--pressing`, `scale(1.05)` за 500мс). Также на мобильных инициализирует свайп влево для ответа через `setupSwipeToReply`. |
| `setupSwipeToReply(msgList)` | Свайп сообщения справа налево для быстрого ответа (только мобильные). Bubble сдвигается по `touchmove` через `translateX` (максимум ~120px). При свайпе ≥ 80px (`SWIPE_REPLY_THRESHOLD_PX`) — активируется `setReply()` с фокусом на input (открывается клавиатура). Направление определяется по тому же принципу, что и свайп закрытия чата (`SWIPE_LOCK_ANGLE_PX`). |
| `openContextMenu(event, messageId)` | Открывает контекстное меню с позиционированием (зажимает к viewport). Определяет видимость кнопок «Редактировать» и «Удалить» по `sender.id` (только свои сообщения). Запоминает фокус input для восстановления после действия. |
| `restoreInputFocus()` | Восстанавливает фокус на input после действия контекстного меню, если input был в фокусе при открытии меню (предотвращает закрытие клавиатуры на мобильных). |

**Кнопка «к последнему сообщению»:**

| Функция | Описание |
|---------|----------|
| `setupScrollDownButton()` | Вешает обработчик клика на `#btn-scroll-down`, создаёт `IntersectionObserver` с root `#messages-list` и threshold 0.1. Регистрируется один раз в `DOMContentLoaded`. |
| `onLastMessageVisibilityChange(entries)` | Колбэк observer. Обновляет `isAtBottom`, при появлении последнего сообщения в viewport очищает `unreadMessageIds`, обновляет UI. |
| `updateScrollDownUI()` | Показывает/скрывает кнопку по `isAtBottom` (через атрибут `hidden`). Бейдж скрыт при пустом `unreadMessageIds`, иначе показывает `size` или «99+». |
| `reobserveLastMessage()` | `disconnect()` + `observe()` нового последнего `.message-bubble`. Вызывается в `selectChat()` (после загрузки), `appendMessageBubble()` и `handleMessageDeleted()`. |
| `resetScrollDownState()` | Очищает `unreadMessageIds`, `isAtBottom = true`, `observer.disconnect()`, обновление UI. Вызывается в `closeChat()` и в начале `selectChat()` (после `scrollToBottom`). |
| `onScrollDownClick()` | Smooth scroll к низу контейнера (`scrollTo({ behavior: 'smooth' })`). Сброс счётчика и скрытие кнопки происходят через observer, когда последнее сообщение становится видимым. |

**Закрытие чата:**

| Функция | Описание |
|---------|----------|
| `setupCloseChat()` | Обработчик кнопки закрытия чата (`#btn-close-chat`). |
| `lockPageScroll()` | Блокирует горизонтальный скролл на `html` и `body` (`overflowX: hidden`). Вызывается при начале свайпа, чтобы `translateX` на conversation не сдвигал всю страницу (включая navbar). |
| `unlockPageScroll()` | Снимает блокировку горизонтального скролла. Вызывается после завершения анимации свайпа (закрытие или возврат на место). |

| `closeChat()` | Сбрасывает состояние чата, скрывает панель переписки, убирает класс `chat-layout--chat-open`, закрывает emoji picker. |

**Мобильная клавиатура:**

| Функция | Описание |
|---------|----------|
| `setupMobileKeyboardDismiss()` | Закрытие виртуальной клавиатуры при тапе в любом месте экрана, кроме textarea (`#message-input`), кнопки «Отправить» (`#btn-send`) и контекстного меню (`#context-menu`). Предотвращает скролл страницы при появлении клавиатуры (`window.scrollTo(0, 0)`). Определяет открытие/закрытие клавиатуры (порог 150px) и добавляет/убирает класс `modal-overlay--keyboard-open` на все модалки, чтобы они поднимались наверх при вводе. |

**Web Push (подписка):**

| Функция | Описание |
|---------|----------|
| `urlBase64ToArrayBuffer(base64String)` | Декодирует base64url в `ArrayBuffer` (для VAPID ключа). Использует `.buffer.slice(0)` для совместимости с iOS. |
| `arrayBufferToBase64Url(buffer)` | Кодирует `ArrayBuffer` в base64url строку. |
| `subscribeToWebPush(registration)` | Получает VAPID ключ с сервера, подписывается на push, отправляет подписку на сервер. |
| `sendWebPushSubscriptionToServer(subscription)` | Отправляет push-подписку через `POST /api/web-push/subscribe`. Сохраняет ID в `localStorage`. |
| `isIOSSafari()` | Проверяет, является ли браузер Safari на iOS. |
| `isStandaloneMode()` | Проверяет режим PWA (standalone). |
| `showWebPushBanner()` | Показывает баннер для запроса разрешений на iOS (требует user gesture). Один раз за сессию (`sessionStorage`). |
| `checkExistingWebPushSubscription()` | Проверяет наличие существующей push-подписки без запроса разрешения. |
| `ensureBrowserWebPushSubscription()` | Полный цикл: регистрация SW → проверка подписки → запрос разрешения → подписка. На iOS требует standalone-режим. |
| `removeBrowserWebPushSubscription()` | Отписывается от push в браузере и удаляет подписку на сервере. |

**Профиль (DOMContentLoaded handler):**

| Функция | Описание |
|---------|----------|
| `convertImageToJpeg(file, maxDim, quality)` | Рисует выбранный файл на `<canvas>` и экспортирует JPEG-блоб. Используется перед загрузкой аватара, чтобы привести HEIC с iPhone к поддерживаемому сервером формату. Заодно ограничивает длинную сторону `maxDim` пикселями. |
| DOMContentLoaded handler | Инициализация: загрузка пользователя, создание кнопки профиля в навбаре, загрузка настроек с сервера. |
| `openMyProfileModal(user)` | Открывает модалку профиля с данными пользователя. Перезапрашивает настройки для синхронизации. |
| `closeMyProfileModal()` | Закрывает модалку, сбрасывает формы и секции. |
| `setupMyProfileToggle(toggleId, formId)` | Настраивает аккордеон-секцию в модалке профиля (редактирование, пароль, уведомления). |
| Edit form handler | Обновление username через `PUT /api/users/me` с валидацией. |
| Password form handler | Смена пароля через `POST /api/users/password/change` с валидацией. |
| `initNotificationToggles(settings)` | Инициализирует toggle-переключатели уведомлений. Авто-синхронизация: если серверное согласие есть, но браузерной подписки нет — создаёт подписку или показывает баннер. |
| Email toggle handler | Переключает email-согласие через битовую маску. |
| Web push toggle handler | Переключает web-push: при включении — подписка в браузере, при выключении — отписка. |
| `visibilitychange` handler | Синхронизирует настройки при возврате на вкладку (другие устройства/вкладки). |
| Logout handler | Удаляет сессию (`DELETE /api/sessions`), сбрасывает тему и куки, редирект на логин. |
