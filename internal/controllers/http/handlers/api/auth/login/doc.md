# Пакет auth/login

## Назначение

Аутентификация пользователя. Устанавливает access и refresh токены в HTTP-only cookies.

## Маршрут

`POST /api/sessions` → `Handler(u, cookiesConfig)`

## Body

`{"login": "...", "password": "..."}`

## Ответы

- `204` — успех, токены в cookies
- `400` — некорректный запрос
- `401` — неверные учётные данные
- `403` — email не подтверждён
- `404` — пользователь не найден
