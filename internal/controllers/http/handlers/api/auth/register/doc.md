# Пакет auth/register

## Назначение

Регистрация нового пользователя.

## Маршрут

`POST /api/users` → `Handler(u)`

## Body

`{"email": "...", "username": "...", "password": "..."}`

## Ответы

- `201` — пользователь создан (JSON с данными пользователя)
- `400` — некорректные данные
- `409` — пользователь уже существует
