# Пакет auth/send_verify_email_message

## Назначение

Отправка письма для подтверждения email.

## Маршрут

`POST /api/users/email/verify` → `Handler(u)`

## Body

`{"login": "..."}`

## Ответы

- `204` — письмо отправлено
- `400` — некорректный запрос
- `404` — пользователь не найден
- `429` — превышен лимит запросов
