# Пакет auth/forget_password

## Назначение

Сброс пароля по токену из письма.

## Маршрут

`POST /api/users/password/forget/{code}` → `Handler(u)`

`{code}` — 6-значный числовой код из письма. Хэндлер парсит его как `uint64` перед вызовом usecase.

## Body

`{"newPassword": "..."}`

## Ответы

- `204` — пароль сброшен
- `400` — некорректный запрос / валидация пароля
- `401` — код не парсится или невалиден
- `404` — пользователь не найден
