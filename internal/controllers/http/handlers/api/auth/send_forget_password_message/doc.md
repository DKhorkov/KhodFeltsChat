# Пакет auth/send_forget_password_message

## Назначение

Отправка письма для сброса пароля.

## Маршрут

`POST /api/users/password/forget` → `Handler(u)`

## Body

`{"login": "..."}`

## Ответы

- `204` — письмо отправлено
- `400` — некорректный запрос
- `404` — пользователь не найден
- `429` — превышен лимит запросов
