# Пакет auth/change_password

## Назначение

Смена пароля авторизованного пользователя (требуется старый пароль).

## Маршрут

`POST /api/users/password/change` → `Handler(u)`

## Body

`{"oldPassword": "...", "newPassword": "..."}`

## Ответы

- `204` — пароль изменён
- `400` — некорректный запрос
- `401` — не авторизован / неверный старый пароль
- `404` — пользователь не найден
