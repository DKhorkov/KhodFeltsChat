# Пакет auth/verify_email

## Назначение

Подтверждение email по токену из письма.

## Маршрут

`GET /api/users/email/verify/{code}` → `Handler(u)`

`{code}` — 6-значный числовой код из письма. Хэндлер парсит его как `uint64` перед вызовом usecase.

## Ответы

- `204` — email подтверждён
- `401` — код не парсится или невалиден
- `404` — пользователь не найден
- `409` — email уже подтверждён
