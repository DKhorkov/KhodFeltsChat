# Пакет messages/get

## Назначение

Получение одного сообщения по ID.

## Маршрут

`GET /api/messages/{id}` → `Handler(u)`

## Логика

1. Получает сообщение через `GetMessageByID` с учётом `userID` (видимость, is_read статус)
2. Маппит в схему и возвращает JSON

## Ответы

- `200` — JSON с сообщением
- `400` — некорректный ID
- `401` — не авторизован
- `404` — сообщение не найдено
