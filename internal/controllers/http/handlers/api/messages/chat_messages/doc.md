# Пакет messages/chat_messages

## Назначение

Получение сообщений чата с пагинацией.

## Маршрут

`GET /api/chats/{id}/messages` → `Handler(u)`

## Query-параметры

`limit`, `offset` — пагинация (опционально).

## Ответы

- `200` — JSON-массив сообщений
- `400` — некорректный ID чата
- `401` — не авторизован
- `403` — пользователь не является участником чата
- `404` — чат не найден
