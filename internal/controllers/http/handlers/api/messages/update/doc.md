# Пакет messages/update

## Назначение

Редактирование текста сообщения (только автор).

## Маршрут

`PUT /api/messages/{id}` → `Handler(u, broadcaster)`

## Body

`{"text": string}`

## Логика

1. Валидирует, что `text` не пустой
2. Вызывает `UpdateMessage` с DTO (usecase проверяет авторство)
3. `broadcaster.BroadcastMessageEdited` рассылает WS-событие всем участникам чата

## Ответы

- `204` — сообщение отредактировано
- `400` — некорректный запрос или пустой текст
- `401` — не авторизован
- `403` — не автор сообщения
- `404` — сообщение не найдено
