# Пакет users/update

## Назначение

Обновление данных текущего пользователя (username).

## Маршрут

`PUT /api/users/me` → `Handler(u)`

## Body

`{"username": "..."}`

## Ответы

- `200` — JSON с обновлёнными данными пользователя
- `400` — некорректный запрос
- `401` — не авторизован
- `409` — username уже занят
