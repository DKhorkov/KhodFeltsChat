# Пакет web_push/subscribe

## Назначение

Создание web-push подписки для текущего пользователя.

## Маршрут

`POST /api/web-push/subscribe` → `Handler(u)`

## Body

`{"endpoint": "...", "keys": {"p256dh": "...", "auth": "..."}}`

## Ответы

- `201` — подписка создана (JSON с ID)
- `400` — некорректный запрос
- `401` — не авторизован
