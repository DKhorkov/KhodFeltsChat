# Пакет handlers/api/settings

## Назначение

Группирующая директория для обработчиков пользовательских настроек.

## Подпакеты

| Пакет | Метод | Путь | Описание |
|-------|-------|------|----------|
| `get` | GET | `/api/users/me/settings` | Получение настроек текущего пользователя |
| `update` | PUT | `/api/users/me/settings` | Обновление настроек текущего пользователя |

## Зависимости

Все подпакеты используют `interfaces.SettingsUseCases`.
