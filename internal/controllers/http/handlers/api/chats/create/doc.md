# Пакет chats/create

## Назначение

Создание нового чата (приватного или группового).

## Маршрут

`POST /api/chats` → `Handler(u)`

## Body

`{"type": "private|group", "memberIDs": [...], "title": "...", "description": "..."}`

## Ответы

- `201` — чат создан (JSON с данными чата)
- `400` — некорректный запрос
- `401` — не авторизован
