# Пакет handlers/api/chats

## Назначение

Группирующая директория для обработчиков чатов.

## Подпакеты

| Пакет | Метод | Путь | Описание |
|-------|-------|------|----------|
| `create` | POST | `/api/chats` | Создание чата (приватного или группового) |
| `user_chats` | GET | `/api/chats` | Список чатов текущего пользователя с пагинацией |

## Зависимости

Все подпакеты используют `interfaces.ChatsUseCases`.
