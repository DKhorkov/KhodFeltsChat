# Репозитории

## Назначение

Пакет `repositories` содержит реализации доступа к данным для всех сущностей системы.
Каждый репозиторий инкапсулирует SQL-запросы к конкретным таблицам базы данных.

## Общие принципы

- Все репозитории строят SQL-запросы с помощью библиотеки **squirrel** (query builder).
- Каждый репозиторий принимает `pg.Transaction` при создании и выполняет все запросы
  в рамках переданной транзакции. Управление транзакцией находится на уровне сервисов
  через Unit of Work.
- Для каждого репозитория реализован **trace-декоратор**, который оборачивает методы
  трассировкой (OpenTelemetry).
- Плейсхолдеры в запросах используют формат `$N` (драйвер `pq` PostgreSQL).

## Подпакеты

| Пакет                | Таблицы                              | Описание                               |
|----------------------|--------------------------------------|----------------------------------------|
| `auth`               | `users`, `refresh_tokens`            | Регистрация, токены, пароли            |
| `users`              | `users`                              | CRUD пользователей                     |
| `chats`              | `chats`, `chats_members`             | Чаты и участники                       |
| `messages`           | `messages`, `messages_statuses`      | Сообщения и статусы прочтения          |
| `reactions`          | `reactions`, `message_reactions`     | Справочник emoji + M2M юзер↔сообщение↔реакция |
| `emails`             | —                                    | Отправка email через SMTP (gomail)     |
| `web_push_subscriptions` | `push_subscriptions`                 | CRUD push-подписок на уведомления      |
