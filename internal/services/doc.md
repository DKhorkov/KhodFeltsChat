# Сервисы

## Назначение

Пакет `services` содержит бизнес-логику приложения. Сервисы являются прослойкой
между use cases и репозиториями.

## Общие принципы

- Каждый сервис оперирует одним или несколькими репозиториями.
- Все обращения к репозиториям выполняются внутри транзакций через **Unit of Work**
  (`interfaces.UnitOfWork`). Функции-конструкторы репозиториев передаются в сервис
  при создании — сервис вызывает их внутри `uow.Do(...)`, передавая текущую транзакцию.
- Сервисы содержат бизнес-правила: проверки на дубликаты, обогащение данных,
  публикацию событий в NATS и т.п.
- Для каждого сервиса реализован **trace-декоратор** с трассировкой OpenTelemetry.

## Подпакеты

| Пакет           | Описание                                                   |
|-----------------|------------------------------------------------------------|
| `auth`          | Регистрация, токены, верификация email, смена пароля       |
| `users`         | CRUD пользователей                                         |
| `chats`         | Управление чатами и участниками                            |
| `messages`      | Сохранение и получение сообщений                           |
| `notifications` | Отправка email-уведомлений                                 |
