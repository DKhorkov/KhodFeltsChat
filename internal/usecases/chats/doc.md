# Пакет usecases/chats

## Назначение

Бизнес-логика для работы с чатами: создание, получение списка чатов пользователя
и списка участников.

## Ключевые операции

### GetUserChats
- Проверяет существование пользователя через `UsersService`.
- Возвращает список чатов, в которых состоит пользователь.

### CreateChat
- Вызывает `IsValid()` у доменного объекта чата.
- Проверяет существование каждого участника.
- Для приватных чатов проверяет отсутствие дубликата (чат между теми же двумя
  пользователями не может быть создан повторно).
- Создаёт чат через сервис.

### GetChatMembers
- Возвращает список участников указанного чата.

## Зависимости

- `internal/interfaces` — `ChatsService`, `UsersService`.
- `internal/domains` — `Chat`, `User`.
- `internal/errors` — ошибки дублирования и валидации.
