# Пакет usecases

## Назначение

Слой бизнес-логики верхнего уровня. Usecase-объекты вызываются HTTP-обработчиками
и оркестрируют сервисы, репозитории и вспомогательные компоненты.

## Ответственности

- Валидация входных данных (форматы, правила домена).
- Оркестрация вызовов к сервисному слою и репозиториям.
- Управление аутентификацией и безопасностью (JWT, хэширование паролей, токены).
- Формирование результатов, возвращаемых контроллерам.

## Подпакеты

| Подпакет        | Назначение                                              |
|-----------------|---------------------------------------------------------|
| `auth`          | Регистрация, вход, выход, обновление токенов, email     |
| `users`         | Получение и обновление пользователей                    |
| `chats`         | Создание чатов, получение списков и участников          |
| `messages`      | Сохранение и получение сообщений                        |
| `notifications`        | Отправка email-уведомлений через NATS                   |
| `settings`             | Получение и обновление пользовательских настроек        |
| `web_push_subscriptions`   | Push-подписки и отправка Web Push уведомлений           |

## Зависимости

- `internal/domains` — доменные типы.
- `internal/interfaces` — интерфейсы сервисов и репозиториев.
- `internal/errors` — доменные ошибки.
- Стандартная библиотека Go + сторонние пакеты (JWT, bcrypt, Redis).
