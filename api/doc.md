# api — OpenAPI спецификация

## Содержимое

- `swagger.yaml` — полная OpenAPI/Swagger спецификация REST API

## Использование

Swagger UI доступен по адресу `http://localhost:8080/docs` при запущенном приложении.

Спецификация описывает все эндпоинты, request/response схемы, коды ответов и аутентификацию.
